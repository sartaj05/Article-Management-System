# Interview feature catalog

The current project already includes the requested product surfaces:

- Global/public and workspace article search with filters and pagination.
- Editor assignment Kanban board with priorities, SLA indicators, comments,
  and an article workflow timeline.
- Article activity/audit timeline, revisions, comments, notifications, and
  correction history.
- Analytics dashboards for workflow throughput, reader engagement, and content
  performance.
- Responsive desktop/tablet/mobile layouts with Playwright visual baselines.
- Accessibility preferences, skip links, semantic labels, keyboard dialogs,
  reduced-motion support, and an article accessibility gate.

Use the demo guide to present these as one connected workflow rather than as
isolated screens.
